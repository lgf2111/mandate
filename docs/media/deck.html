A mandate

Rules in a database,
not a sentence in a prompt.

  • The agent can read these rules.
  • It cannot rewrite them.
  • They are checked in code at checkout.
  • A human approves, not the model.

Trust boundary

One function decides. Nothing else does.

Agent · untrusted

  • Proposes SKUs from a fixed catalog
  • Writes its own rationale
  • Can be wrong, or manipulated
  • Never sees a payment credential

evaluate() · trusted

  • Pure: no clock, no network, no randomness
  • 16 unit tests, cent-exact boundaries
  • Re-runs at checkout, reads spend from the store
  • Returns written reasons, not a boolean
